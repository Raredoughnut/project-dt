## Project DT

### 개요
- 도넛테스트(donutest)는 로그인, 회원가입 없이 30초만에 가볍게 즐기고, 공유하고 싶어지는 결과를 주는 심리테스트 플랫폼입니다.
- MBTI 테스트는 이미 유사한 서비스가 많으나, 선명한 브랜딩과 좋은 접근성으로 차별점을 두고, 적극적인 바이럴을 통하여 이용자를 확보하는 것을 목표로 하고 있습니다.
- 서비스를 기획하고 개발하는 인원에게도 실무 경력을 쌓을 수 있는 좋은 경험이 될 수 있도록 하는 것 역시 목표로 삼습니다.

### 사이트의 목적
- 개발자의 입장에서
	- 가볍게 소비되는 심리 테스트를 통하여 유의미한 트래픽을 경험하고 운영 경험을 쌓을 수 있습니다.
	- 추후 취업이나 이직에서 해당 서비스를 운영해본 것을 강점으로 어필할 수 있습니다.
- 디자이너/마케터의 입장에서
	- "도넛" 이라는 키워드를 토대로 브랜드를 구축하는 경험을 할 수 있습니다.
	- 테스트 컨텐츠를 제작함으로써 컨텐츠 제작 능력을 키울 수 있습니다.
	- SNS 바이럴을 통하여 서비스를 홍보함으로써 바이럴 마케팅에 대한 실무 경험을 쌓을 수 있습니다.

### 타겟 사용자
- 성별 무관, SNS를 즐겨 하는 10~30대
- 핵심 타겟은 10~20대 여성


### 핵심 기능

- 메인 페이지
	- 서비스의 정체성을 잘 나타내는 배너를 표시합니다.
	- 메인 페이지에는 다음과 같은 테스트 목록을 보여줍니다.
		- 최신 테스트: 가장 최근에 올라온 테스트
		- 인기 테스트: 최근 일주일 간 가장 많은 테스트 수를 기록한 테스트
		- 추천 테스트 세트: 운영자가 임의로 묶은 테스트
			- 올여름, 나를 표현하는 아이템들은?: 나는 무슨 과일? / 나를 음료수로 표현한다면 / 과자 테스트
	- 찾는 테스트가 없는 경우 검색창에서 검색하여 찾을 수 있도록 합니다.
- 각 테스트 페이지
	- 테스트는 다음과 같은 순서대로 진행합니다.
		- 메인 페이지: 해당 테스트의 메인 이미지를 보여주고, 테스트 시작하기 버튼으로 테스트를 시작하도록 합니다.
		- 이름 입력창: 내 이름을 입력하여 개인화할 수 있도록 합니다.
		- 테스트 페이지: MBTI 테스트를 진행합니다.
			- 문항은 유형별로 각 3문항 혹은 4문항
			- 선택지는 2개 혹은 4개
			- 진행률은 막대와 진행률 텍스트로 보여줍니다.
		- 답안 채점: 답안 채점 애니메이션을 2~3초정도 보여줍니다.
		- 결과창
			- 채점지를 보여주고, 이미지를 다운로드받거나 링크를 공유할 수 있도록 합니다.
			- 추천 테스트를 보여주거나 다른 테스트를 보러 갈 수 있는 링크를 보여줍니다.

- 수익 모델: Google AdSense, 쿠팡 파트너스 등 링크를 통한 광고 수익
